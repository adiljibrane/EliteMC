🔗 On-Chain Minting Process (Future)

  1. Ensure property status is READY_TO_MINT
  2. Verify all shareholders have connected Polkadot wallets (SS58 addresses)
  3. Export allocation CSV for batch processing
  4. Create Asset on Polkadot Asset Hub using @polkadot/api
  5. Record asset_hub_asset_id in property table
  6. Mint total supply to admin wallet
  7. Batch transfer tokens to shareholders based on allocations
  8. Update onchain_tx_hash and onchain_block
  9. Update allocation statuses to ONCHAIN_SETTLED
  10. Update property status to MINTED

Note: This MVP operates off-chain. On-chain integration requires @polkadot/api, Asset Hub testnet/mainnet connection, and an indexer for confirmation tracking.
